使用方法

  • 打开抽卡计算器： https://genshinpull.pages.dev
  • 填写已有资源： 在「已有粉球」框中输入你目前持有的纠缠之缘数量。
  • 设定目标： 在「角色A/B」和「武器A/B」中填入想要的命座或武器数量。满命填7，专武填1。捕获明光与命定值会自动计算，如同舞步与倒影般精准对应。
  • 模拟次数： 「模拟次数」默认十万次。分批计算，不会造成卡顿。
  • 开始计算： 点击「开始计算」按钮。
  • 查看结果： 下方会显示成功率。若低于75%，说明当前资源不足，需要继续获取原石。
