## Pull requests

- Body: the problem in a sentence or two, then how you fixed it. End with the model and harness that did the work.
- Interface changes need before/after screenshots of the same page in the same state. If the layout changes, include both desktop and mobile widths. Motion, timing, transitions, or interaction details need a short before/after video.
- Upload PR evidence to GitHub and embed or link it in the PR body. Never commit PR-only screenshots or videos.
- If you cannot capture evidence, say what you could not show and why.
